你的设备确认

        
按你给的引脚（麦克风 40/42/41，喇叭 17/18/8，屏幕 11/10/12/13/9，背光 46、BOOT 0、充电检测 14），固件仓库里对应的板型就是 electron-bot。即使你的外壳没有头和手脚，PCB 仍是这一款，直接用这个板型编译即可。

        
硬件层的 C/C++ 代码（屏幕、麦克风、喇叭、电池、背光）仓库里已经全部实现，你不需要再写引脚操控部分。你负责：确认板型、编译/烧录、验证硬件、做操控平台；伙伴负责 WiFi 连接后的 agent，通过 MCP 工具调用硬件能力。

      


      

        
1. 编译固件（伙伴或本地）

        
在 ESP-IDF v6.0.2 环境下执行：

        
python scripts/build.py electron-bot --name electron-bot

        
产物在 build/merged-binary.bin。也可以用 idf.py menuconfig 修改 CONFIG_OTA_URL 后 idf.py build。

      


      

        
2. 启动平台

        
在 platform/ 目录下运行：

        
python -m http.server 8011

        
然后用 Chrome 或 Edge 打开 http://localhost:8011。Web Serial 只在这两个浏览器且必须是 HTTPS 或 localhost 下可用。

        
如果你机器上 8000 端口已被其他服务占用（比如另一个 Python 服务），请用 8011 或直接运行 start.ps1 自动选端口。不要直接双击 index.html，浏览器会拦截模块脚本导致页面卡住。

      


      

        
3. 烧录

        
    
          
  1. 设备用支持数据传输的 USB 线连接电脑，确认系统出现新的 COM 口（之前的 COM6/COM7 是蓝牙串口，不是 ESP32）。
    2. 
          
  2. 打开 ESP Launchpad。
    3. 
          
  3. 选择 merged-binary.bin，从 0x0 写入，点击烧录。
    4. 
        

      


      

        
4. 配网与操控

        
    
          
  1. 设备首次启动会进入配网热点，手机连上后配置 WiFi。
    2. 
          
  2. 在路由器后台或设备日志里找到设备 IP。
    3. 
          
  3. 进入“操控”页，填入 IP（端口 8080），点“连接”，即可看到固件上报的全部 MCP 工具。
    4. 
          
  4. 音量、亮度、主题、状态查询已做成快捷按钮；其余工具按表单填写后调用。
    5. 
        

      


      

        
5. 切换到你自己的服务器

        
    
          
  1. 先部署 xiaozhi-esp32-server（Docker 或源码），确认 OTA 接口 http://主机IP:8002/xiaozhi/ota/ 和 WebSocket ws://主机IP:8000/xiaozhi/v1/ 可用。
    2. 
          
  2. 在服务器管理后台的“固件配置”里填写固件 type=electron-bot、name=electron-bot。
    3. 
          
  3. 设备配网页的“高级选项”中把 OTA 地址改成你的服务器，重启设备，激活流程会下发新的 MQTT/WebSocket 配置。
    4. 
        

      

    


    

      
关于操作权限

      
本平台默认每次控制类操作都会弹出确认框，点“允许”才会执行；状态查询自动放行。烧录走官方 ESP Launchpad，不经过本平台。

      
如果伙伴的 AI agent 要通过服务器控制设备，需要在服务器端单独做权限/审批，网页确认框管不到那条链路。
